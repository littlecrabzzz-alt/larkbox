## Template

When proposing a major design change, copy this template to `docs/adr/NNNN-short-title.md`:

```markdown
# NNNN. Short Title

- **Status:** Proposed | Accepted | Deprecated | Superseded
- **Date:** YYYY-MM-DD

## Context
What problem or trade-off are we addressing?

## Decision
What did we decide to do?

## Consequences
What becomes easier, harder, or constrained because of this decision?
```
